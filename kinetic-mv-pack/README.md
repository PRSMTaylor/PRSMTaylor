# Kinetic MV Pack (KMV) for DaVinci Resolve

An original pack of Fusion-based **Edit page effects** for music-video style cuts: flashes, **strobes**, **stutters**, shakes, zooms, slides and blurs. Every preset comes in **Pre** and **Post** versions. Search `KMV` in *Effects > Edit Effects*.

> **Testing status:** the `.setting` files are generated by script and checked structurally only (balanced braces, tool/expression references; `tools/validate.py`). They have **not been loaded in DaVinci Resolve** (not available when this was built). Tool/input names (e.g. `TimeStretcher`, `Glow`, `Defocus`, `DirectionalBlur`) follow Fusion conventions but may need small fixes in your Resolve version. See *Known caveats*.

## Install

- **Windows:** `powershell -ExecutionPolicy Bypass -File .\Install-KineticMV.ps1` (add `-AllUsers` for ProgramData, `-Uninstall` to remove, `-WhatIf` to preview, `-Destination <dir>` to override).
- **macOS:** `./install.sh` (`--all-users`, `--uninstall`).
- The installers also copy the launcher script to `Fusion\Scripts\Edit` (`-ScriptsDestination <dir>` on Windows).
- Manual: copy `Scripts\*.lua` to the Fusion `Scripts\Edit` folder next to `Templates`, and `Effects\*.setting` to
  - Windows: `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Effects`
  - macOS: `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Effects`

Restart Resolve afterwards.

## Quick start

1. Put the effect on the clip at a cut: **Pre** on the outgoing clip, **Post** on the incoming clip (drag from Effects onto the clip, or Inspector > Effects).
2. **Pre** = effect builds up over the *last* `Length` frames and peaks on the final frame. **Post** = effect starts at its peak on the *first* frame and fades out over `Length` frames.
3. Tweak controls in the Inspector (Intensity, Length, Strobe Count, etc.). No keyframes needed.

The window is set by the **Length (frames)** slider and measured from the clip's ends, so it stays correct when you trim.

## Launcher script (Workspace > Scripts > Edit > KMV Effects Launcher)

A browser window: **search** the effect list, filter **ALL / EFFECTS / MOTION / FAVS**, toggle **Favourite** (saved to `KMV_favourites.txt` in your AppData / Library folder), read the description, set Length, Intensity, Strobe/stutter count, Hold/echo frames, Amount, Speed, **Curve** (Smooth/Sharp/S/Linear), **Seed/Randomize**, Motion blur and Brightness, then press **PRE**, **BOTH** or **POST**.

Each press inserts an **adjustment-style clip at the playhead** and loads the KMV effect into its Fusion comp, so you can select it, trim/stretch it and keep adjusting afterwards. PRE clips end at the playhead, POST clips start at it. The same controls (Strength, Curve, Seed, Motion Blur, Brightness, plus effect-specific ones) are also on every preset in the Effects panel.

Honest limits (**untested in Resolve**; written from the scripting docs):
- API calls are tried in order: `Timeline:InsertGeneratorIntoTimeline("Adjustment Clip")`, `InsertFusionGeneratorIntoTimeline`, `InsertFusionCompositionIntoTimeline`, then `TimelineItem:ImportFusionComp()`. If one is unavailable the status line says what to do manually (a `.comp` file is left in your temp folder).
- **Track handling:** before inserting, the script reuses the top video track if it is empty around the cut, otherwise adds a new track above everything (Timeline:AddTrack). Existing clips are never moved. The API has no insert-target setter, so it locks the other video tracks during insertion (restoring their lock state afterwards), then verifies the clip's track via GetTrackTypeAndIndex and reports a warning in the status line/Console if it landed elsewhere. If a media pool item for the generator can be obtained, it re-places the clip with AppendToTimeline at exactly Length frames; otherwise the clip keeps Resolve's default generator length and you can trim it.
- A plain Fusion Composition does not see the clips below it; the Adjustment Clip generator does. If only the Fusion Composition fallback is used, the effect will not affect underlying video.
- Previews are text descriptions only; no thumbnails/animated previews.
- Playhead handling assumes non-drop-frame timecode. Scripts run from Resolve's Scripts menu work in the free version; running scripts externally needs Resolve Studio.
**Defaults are short and punchy** (about 4-10 frames; flashes 3-6, strobes/stutters 8-10) with a sharp curve by default (fast attack, quick decay). Length range is 1-30 frames. Only the three Shake presets shake; every other family uses its own node graph (flash = Merge/Glow, stutter = TimeStretcher, zoom/slide = Transform, blur = Blur/Defocus). The launcher prints which preset and tool types it loaded to Resolve's Console so you can confirm the right macro was used.

|---|---|---|
| Flashes | Flash, Color Flash, Glow Flash | Intensity, Length, (RGB color) |

## Known caveats

- Stutter presets use `TimeStretcher` to sample other frames; on the Edit page this relies on handle/adjacent frames being available. If a freeze looks wrong, check that the clip has source media beyond the cut.
- Shakes scale up slightly (Amount-driven) to hide edges; slides and zoom-pull show empty edges by design.
- Flash/strobe colors appear as Red/Green/Blue sliders (0–1).
- Power Bins and a PDF guide are not included.

## Rebuilding

`python tools/generate_settings.py` regenerates `Effects/`, then `python tools/validate.py` lints it. Edit the generator, not the `.setting` files.
